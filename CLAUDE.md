# Keyify standing rules

## Cache version
Every change that touches a data file, a keys-*.js file, group.js, script.js or the styles must bump the ?v= number by one on all script and stylesheet tags in index.html, and any new keys-*.js file gets the same version number.

## Standing rules
- The data supplier is never named, linked or shown anywhere on the site or in files. This applies to the page, every code file, every data file and every note. No supplier name, no supplier links.
- No SKUs appear in any file.
- Nothing merges until Danish says "merge it".
- Never edit the raw source files, only cleaned ones. The CSVs in data/ are the cleaned ones; the original uploads stay as they are.
